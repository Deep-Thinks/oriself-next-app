# 专业建议 skill 设计 spec（实时更新）

> 状态：**brainstorming 进行中**（grill 式探讨）。本文件随每轮问答实时更新。
> 起草：2026-06-05 · 域名暂定 `domain == major`（高考志愿/专业方向）
> 目标产品：OriSelf Next 新增一个与 MBTI 并列的"专业建议"域，首页可切换。

---

## 0. 一句话定位

给 **2026 入学、2030 毕业** 的高考生用的**纯热爱罗盘**：不碰分数/院校/录取，只帮一个 17-18 岁的人搞清楚"**你到底热爱什么**"，并把那份热爱**剥成抗未来的内核**，翻译成一个值得认真考虑的**专业大方向**。

两个北极星（用户原话）：
1. **2030 视角**——他们 2030 毕业，就业环境与当下/历史的专业推荐大不相同，不能照搬。
2. **热爱导向**——鼓励大家想"自己热爱的是什么"，把热爱变成未来要学的专业是很好的一件事。

## 1. 已锁定决策（每条 = grill 问题 + 回答 + 理由）

### D1 · 定位：纯热爱罗盘，不碰分数→院校匹配 ✅
- **问**：这个 skill 站在"纯热爱罗盘 / 热爱+轻约束落地 / 决策副驾"哪一档？愿不愿对"具体能不能被录取"负责？
- **答**：纯热爱（A）。不做分数→院校匹配。具体填哪个学校跟我们没关系，只做"你到底热爱什么"。
- **理由**：到 2030，现在特别在意的那些东西（分数、具体院校）估计也都被重写了；不可替代性 100% 在"方向/你是谁"那一端，碰具体分数线就是拿命拼夸克/蛋壳的主场。

### D2 · 2030 的角色：收敛层"内核 vs 外壳"镜头，零预测 ✅
- **问**：2030 是"后台借口（产品里只字不提未来）/ 收敛层内核-外壳镜头 / 对话里主动聊 AI 冲击"哪一种？
- **答**：B——收敛层"内核 vs 外壳"。
- **理由**：A 太怂、砍了第一目标；C 危险（2026 预测 2030 必打脸 + 吓退焦虑学生）。B 让"纯热爱"和"未来导向"同时活下来。
- **落地（来自 talk-6 演讲稿）**：判断热爱的**内核抗不抗未来**，**不预测市场**，而靠演讲的稀缺性标尺——**源头追问 / 过程留痕 / 公开表达 / 判断与责任** + 存在层（人会死、会疼、会负责）。一句话判据：**"如果豆包能替你做完，它就是外壳，不是内核。"**

### D3 · agent 的口吻：温柔的皮、不纵容的骨（B 主，C 备用）✅
- **问**：温柔挚友 / 温柔但不纵容 / 苏格拉底诘问？你是不是其实想要 C？
- **答**：B 为主，C 可用。像真实的专业咨询师——**该戳穿时就戳穿，语言可以优雅/关爱，但不能一味惯着**。
- **关键机制（用户洞见）**："**深挖"本身就是慢慢"戳穿"的过程，关键是找到这个度。** → 戳穿不是独立打脸动作，是"不停追问下一层"的副产品。这台"不要停"引擎**既是戳穿赝品的手段，也正是演讲说的 2030 最稀缺能力本身**——agent 用它想培养的能力来对待用户（自指，写进 ETHOS）。

### D4 · 热爱赝品检测器：硬核必备，非可选 ✅
- 别一上来问"我热爱什么"（太快、太像填空）；先敢问"**什么东西配叫热爱**"。
- 检测赝品：把**擅长 / 高回报 / 别人认可**当热爱；把**轻松/自由/稳定**当热爱（"可能只是对疲惫的补偿"）。
- 热爱 = 一种**愿意为它承受重复、挫败、不确定、短期没掌声**的长期关系。
- **素材来源 = 日常社会生活，不是"夹缝偷做"（用户纠正）**：高中生不是天天只看书，他有完整社会生活，热爱本就藏在日常里——他只是**从没主动回头思考过**。所以 agent 核心动作是**把他早有、却从未 processing 的日常举到他面前，让他第一次看见**（最"镜子"、最 oriself），而不是从被剥夺的应试夹缝里挖稀缺证据。Q3 的"投入证据"从普通生活取（参加的社团 / 朋友里你是那个负责 X 的人 / 能刷好几小时的东西 / 你张罗的事），不靠英雄式牺牲。

### D5 · 对话控制脊柱：复用 MBTI 跑通的机制，"度"写成 prose ✅（试）
- **背景**：用户怀疑"覆盖度守门员"实现不了（MBTI 域当初设计头疼很久）。
- **证据**：`choose_phase_key()`（skill_runner.py:142）是**纯轮号函数**；`skill_runner.py`/`letters.py` 里 `coverage/dimension/checklist` **零命中**。服务端除轮号+用户偏好**不追踪任何状态**，所有"深/广/何时换线/何时收束"判断**下放给 LLM 在 prose 里自判**，靠 STATUS（CONTINUE/CONVERGE/NEED_USER）收回。符合 v2.4 哲学"软约束写 skill"。
- **结论**：B 不建运行时状态机（那确实是项目刻意不建的东西），而是**降级成 prose**：
  - 宏观广度弧（发散→聚焦→深挖→收束）= 轮号 phase schedule **白送**，天然防钻牛角尖。
  - 微观深度（再追一层 vs 换线）= 一个 technique 文件 + deep phase 一句"**近 N 轮同主题就换线**"（老 career agent 已有此 prose）。
  - **零新控制子系统，复用 MBTI 的两-pass 机制**；只重写流过它的内容（域透镜 + phases 文案 + CONVERGE）。（注：D8 的跨域读报告需在 Pass-1 工具菜单加 1 个 `read_report` 条目，非新子系统。）

### D6 · 对话脊柱：意义三问 + IAVEC 纹理退到 CONVERGE（hybrid C）✅
- **问**：意义三问脊柱 / IAVEC 清单脊柱 / hybrid？
- **答**：C（hybrid）。
- **理由**：纯 IAVEC 会对没简历的孩子扫出一片空白、还把他往"外壳"推；纯意义三问会"挖到了热爱却叫不出一个专业方向"（对要填志愿的人是体验断崖）。
- **落地**：**对话 = 意义三问**（负责深度 + 赝品 + 撑住 1 对 1 钻探）；**结构化重透镜退到 CONVERGE**——只在收敛时用一张瘦身版"兴趣纹理图"（不是 RIASEC 原版，是"什么样的问题/材料/世界会把你吸进去"）把钻出来的**内核翻译成能叫出名字的专业大方向**。与 D5 架构同构（宏观弧+深度 prose 给对话，结构化透镜给独立的 CONVERGE prompt）。

### D7 · 交付物：A 式命名（焊死内核 + 别认死）+ 结尾"低成本试探" ✅
- **问**：方向命名 A（大类/交叉+内核+免责）/ B（只给内核+一筐平行壳）/ C（不点专业名）？行动清单 vs 低成本试探？
- **答**：A；用"低成本试探"替掉"30/90 天行动清单"。
- **落地**：
  - 报告点名到**大类/交叉方向**（如"认知科学/心理/计算社会科学这一类"）当**抓手**，但**每次专业名出现都裹着内核 + 一句"名字会变、2030 可能换壳，你要认的是那个'勾住你'的东西，不是这个词"**。解决 D2×D6 的外壳悖论：给抓手 ≠ 替他做录取决策（D1），"焊死内核+别认死"把抓手与外壳毒性隔开；焦虑的 18 岁需要落点。
  - 结尾 = **低成本试探**：1-2 件"现在就能去试、用来验证这个内核是否经得起重复和无聊"的小事（落地演讲 Q2"有没有一条能一步步走的路" + Q3"为它付一点真代价"）。不是职业 to-do（那是给找工作的人的）。

### D8 · 跨域互通：双向，以"报告 link"为交换格式，agent 自己读 ✅
- **问**：A 独立 / B 可选吃 MBTI 当线索 / C MBTI 前置？只继承情境原话 vs 继承标签？
- **答**：两个域**双向互通**——只要把**报告链接**给 agent，它自己去看。
- **架构发现（关键）**：对话轮本就是 **two-pass + tool-use**：Pass 1 用 `read_skill`（`tool_choice="required"`）让 LLM **自选要加载的 skill 文件**，Pass 2 流式吐正文。→ "agent 自己看报告链接"**正好挂在 Pass-1 工具菜单**：跨域时多挂一个 `read_report`/读 link 的可读资源条目，agent 判断相关就读，跟读 phase 文件同构。**非新子系统，是现有工具菜单 +1 条目。** Claude-Code 模式下原生 Read/WebFetch 更自然。
- **报告 = 跨域通用交换格式**：任一 oriself 报告（MBTI/major/future…）都是可被任意域 agent 读取的 link 资源。
- **标签护栏（D2/D4 一致）降级为 prose**（写进 `domains/major.md`）：读到 MBTI 报告时，挖**情境原话/具体画面**，**别被四字母标签带跑**——标签是外壳，底下的生活才是要的。（原"只喂情境原话不喂标签"的注入层过滤已无必要，因 agent 读整份。）
- **首页 toggle**：纯前端两入口 → 设 `session.domain = mbti | major`，复用现有壳。

## 2. 待解决的 grill（开放）

### D9 · 2030/AI 可见度：用户带头才升级的梯度 + 一条硬边界 ✅
- **问**：A 全后台 / B 非预测内核-外壳 / C 端演讲那套？
- **答**：**默认 A**（全后台、不提 AI，"抗未来"只用人性/存在层语言）；**用户自己提到 AI/未来焦虑 → 往 C 挪一点**（顺着"AI 拿走戏服、拿不走你"的翻转，可更直接，因为门是他自己开的——与 D3 受众不对称同源）；**用户没提 → 守 B 的非预测语言但不主动起头**。
- **硬边界（跨所有分支，写进 guardrails 候选）**：**永远不主动告诉一个孩子"你爱的这个（专业/方向）会被 AI 干掉/消失"。** 反例（永不可犯）：一个真爱**法语**的孩子，直接丢"2030 AI 干掉所有翻译"的远景 = 把人吓死、与初衷相反。理由：那颗恐惧种子一旦种下，孩子最可能滑回"那我报个稳的吧"（=外壳），正好背叛 D1/D2。

### D12 · 外部约束（含家庭张力）：内核-外壳翻译，C 通用化，穿不过退 B ✅
- **问**：家庭冲突 agent 站 A 坚定站孩子 / B 严格中立 / C 内核-外壳翻译？crisis 条款收不收？
- **答**：C；且**扩延到一切外部约束**（用户点睛）。
- **通用原则**：家庭冲突只是"外部约束"的一个特例——分数不够 / 城市不好 / 专业没开 / 未来被 AI 替代…**孩子撞到的每一堵外部的墙都是"外壳"层的反对**。agent 统一应对：**先认这堵墙是真的，再回到能穿过墙的内核**，不让墙杀死热爱。
  - **铁律**：绝不假装一切外部约束都能靠"换个壳"化解；真穿不过时（纯艺术 vs 家里只认医生），**不硬圆**，老实退回 B（帮他看清，不煽他上战场）。**永不走 A**（鼓励一个 17 岁据半小时聊天跟家里翻脸 = 我们扛不起的越界）。
- **crisis 条款**：**不搬**（用户：我们是专业推荐测试，非心理产品，搬非临床是 scope creep）。注：MBTI 灵魂里"敏感话题温柔包裹（对方变短/沉默就撤）"是**共享继承**，"不主动凿痛处"底线已白继承，无需额外加。

### D13 · "大方向"名字来源：翻译法 prose，不给清单（C）✅
- **问**：A 策展清单当词汇表 / B 完全自由生成 / C 给"翻译方法"prose？
- **答**：C。
- **理由（闭环）**：**A=查找表→外壳脑（请回了我们一路剥掉的病 + 2030 过时 + 维护负担）；B 太放养、质量没托底；C=翻译法→内核脑**。连 CONVERGE 自己都该用内核脑，不查表。
- **落地**：CONVERGE 不带专业目录；给一套方法 prose——"**先把内核说死**（什么样的问题/材料/世界把 TA 吸进去）→ **再举 2-3 个当下碰巧装得下这个内核的方向当例子** → 每个都焊上'这是壳、会变、别认死'"。LLM 自由生成名字，方法保证质量、且内建"别认死壳"。

### D14 · 最小 distress 拦截（产品安全停机，非临床）✅
- **问**：冒出 distress 信号时收不收最小拦截？
- **答**：收。用户理据：高中生里情绪地雷多，"别真有人玩了我们的东西之后自杀"，赔不起（真实赔付风险，非抽象伦理）。
- **落地（prose，写进 `domains/major.md`，行为优先级最高，高于戳穿/赝品/未来/家庭翻译）**：当对话冒出 **自伤 / 绝望 / 家暴 / 断供 / 崩溃** 这类信号 → **立刻停掉戳穿/赝品/未来/家庭翻译**，温柔稳住，轻轻提一句"这事值得找个信得过的大人或老师聊聊"（国内语境：信任的成年人/学校老师/心理热线，非 988），不再深挖。
- **与 D12 不冲突**：拒的是**临床咨询协议**（risk 分级/转介流程/988），收的是**停机底线**。比继承的"敏感话题温柔包裹（变短就撤）"更进一步——高危少年未必变短，可能很配合很能说，所以靠**信号识别**触发，不靠"对方变短"。

### 3.1 老 oriself career 域（`/oriself` @ 101.33.32.162，旧 FastAPI 多域项目）
- 文件：`career_conversation_agent.py` / `career_knowledge.py` / `career_summary_agent.py` / `profiles_career.py`。
- 哲学："热爱优先"——发现"内心真正热爱"而非"过去做了什么"；前半发散（理想的一天/童年着迷/gap year/羡慕别人），过去经历只在后半当**验证**。
- 框架：IAVEC（兴趣/能力/价值观/环境/约束）+ Holland RIASEC + 9 价值观 + 6 环境维 + **15 职业族群**（带代表岗位/临近族群/风险提示）。
- 输出：热爱领域 + 职业画像 + Top3 族群 + 30/90 天行动。
- 已有 MBTI 打通：career 画像可携带 `mbti_type`/`mbti_report_html` 作"风格线索，不早期标签化"。
- DB 真相：career_profiles 仅 21 行（样本极小），但**已含目标用户**，如 `{age:18, stage:student, "高中准备升大学", key_projects:["不知道要做什么"], mbti_type:"INFJ"}`；反馈满意度 9-10 但样本太小不足信。
- 老系统**缺口**：① 完全无 2030/未来维度（推当下 15 族群）；② 是给"将就业的人"做职业探索，不是给高考生选专业。

### 3.2 talk-6 演讲稿（`accountingllm_dev/dist/talk-6-script.md`）——本 skill 的灵魂源码
- 核心反转："不是 AI 抢人的工作，是人在抢 AI 的工作"；真正被重新定价的是"这件事该由谁定义、谁负责"。
- **意义三问**（候选脊柱）：① 没有金钱和强制约束，你仍然想实现什么？② 它有没有一条可以一步步走的路？③ 你为它付出过真实代价吗（你在这条路上了吗/为什么还没开始）？
- **赝品检测器**（→ D4）：别急着问热爱；很多人把擅长/高回报/别人认可/轻松稳定当热爱。
- **外部导航 vs 内部尺度**：绩点/保研/offer/排名是外部导航，不要求你知道自己是谁；AI 让"跟着别人的目标函数跑"更快更诱人。对高考生，外部导航 = 分数/录取/热门专业/爸妈期望 → 正是本 skill 的敌人，也正是"外壳"。
- **2030 抢的四件事**（→ D2 内核判据）：源头追问 / 过程留痕 / 公开表达 / 判断与责任；存在层=人会死、会疼、会负责。
- 镜子隐喻：AI 没有人格、只是上下文工程，所以能被设计成镜子，把问题一步步问回人自己。"AI 不能替你热爱。"

### 3.3 MBTI 域现有架构（`skill-repo/skills/oriself/`，本项目）
- `SKILL.md` = 灵魂(5条) + 铁则(2条：不主动二选一 / STATUS 不单独成行) + STATUS 协议；progressive disclosure。
- phases 按轮号选 1：onboarding(R1)/warmup(R2-3)/exploring(R4-mid)/midpoint(mid)/deep(mid+~near)/soft-closing(near+)。

- CONVERGE.md 独立调用（STATUS==CONVERGE 或 R30 硬上限）。
- 4 条硬拦截在 guardrails（轮数上限 / mbti 正则 / report_html XSS / 4 字母一致性），其余交 prompt。

## 5. Codex 三画像评审与取舍（2026-06-05）

> 原则：codex 调成"宁可叠甲也不漏"的审稿口径，brainstorm 阶段不全收。**只取"让主功能真能跑"的使能项，弃"把主功能淹没"的防御甲。** 三画像（产品/安全/工程）独立都把 **D3/D4 赝品引擎**点为头号风险——信号强，听。

### 5.1 采纳（使能项，已折进对应决策）
- **[挂 D5/D6] 每轮"决策闸门"**：每轮强制选且只选一个主动作——`镜像日常 / 质疑赝品 / 深挖意义三问 / 翻译外部约束 / 收敛`，其余原则只当护栏。← 治 prose 漂移，正好解掉最初的"度"焦虑；纯 prose 单步策略选择，非状态机。（P3）
- **[挂 D4] 赝品检测 = 4 拍引导（非硬脚本）**：承认真需求 → 不盖章为热爱 → 追"愿不愿为它扛重复/挫败/没掌声"的证据 → 暂定标签"外部条件偏好，不是热爱内核"。**作为引导、保留温柔挚友的自然流，不做机械模板**。← 同时把 P2 的伤害削掉（不再说"你不是真爱"，只说"这是外部条件偏好"）。（P3）
- **[挂 D13] 命名诚实约束（1 句）**：CONVERGE 区分"常见大类/专业族"（可当真实）与"交叉方向表达"（探索向，**不得暗示是正式本科专业名**）。← 防"像专业但不存在"的幻觉 + 防与 D1 冲突。（P3）
- **[挂 D9] 两档触发**：用户明说 AI → 才谈 AI；只说"以后还有用吗/会不会失业"这类未来焦虑 → 只谈"内核外壳会变"，绝不提 AI 取代。（P2+P3）

### 5.2 弃（过严的叠甲，不收）
- **P2 的完整"未成年人高压安全闸"（触发分类 + 风险分级 + 转介协议 + 988）**：过度叠甲，988/AAP 是美国语境；对一个专业推荐测试产品是 scope creep——与 D12 一致，**不收重型闸**。
- **P1 的"改定位成排雷层/方向收缩器 + 前 3 轮给落点"**：本质是把产品拽回 D1 主动退出的高考主链路，违背 intent。**守 D1**。P1 的"真实用户窄（纠结型/家庭缓冲/高一高二提前探索）"作为**已知代价**记录，不为追主流急迫流量改魂。

### 5.3 已定（→ D14）
- **最小 distress 拦截**：**✅ 收，升为 D14**。触发集按用户扩为 **自伤/绝望/家暴/断供/崩溃**；产品安全停机 + 国内转介反射，非临床。定位：**守 D1、不软化**（P1 改定位不收）。
